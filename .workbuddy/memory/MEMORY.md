# 福建海运集团 POC · 项目长期约定

## 状态配色口径（2026-10-25 用户明确要求）
- **不用品牌金/棕表示「未配置」**：这套系统里金色 = 待人工（业务结论），未配置是配置缺失，混用会误读。用户原话「这种颜色就跟屎一样」。
- 四态固定色（淡底 + 深一档文字，不用饱和红绿）：未配置/不通 #FEF3F2 + #B42318；已就绪 #ECFDF3 + #067647；未测试 #475467（中性，不许冒充绿）；停用中性灰。
- 卡片结构参考 integration card：头部（图标+名称+状态点）→ 一句话职责 → 当前配置块 → 约束说明 → 底部右对齐操作。**不要用大虚框占位块**当空态。

## 表格对齐口径（2026-10-25 定）
- **文本/编号/摘要 → 左对齐**（阅读起点固定，长度不一）。
- **金额/数量（带小数）→ 右对齐 + tabular-nums**，绝不允许居中：居中的金额无法按位值比较大小，这是财务界面铁律。
- **短状态/短计数（结论、执行次数、命中数、操作）→ 居中**（`.v2 .c`），内容 2–4 字、列宽固定，居中重心稳。
- **长文本/路径 → 左对齐 + 省略号**（`.t-cut`），尾部省略比整体截断好。
- 一句话：文本看左边，数字看右边，短标签看中间。

## 前端设计系统（design.css / .v2 兼容层）
- **禁止给 `.v2 button` 写固定 `height`**：智能体拓扑节点、附件卡、开关都是 button，固定高度会把内容裁掉并溢出到卡外（2026-10-25 三层泳道互相压字的事故根因）。用 `min-height`。
- **选中态类名用 `.sel`，不用 `.on`**：`.v2 button.on` 是深蓝底白字，节点卡一选中就整块填色。
- 自定义卡片组件的 grid 列宽按 `repeat(auto-fill, minmax(最小宽, 1fr))` 铺，别用 `grid-auto-flow: column`（每行独立算列，会做出同页多种卡宽）。
- **新页面的 CSS 类名一律带页面前缀**（如 `dv-`），不要用 `qbar` / `qt` / `ck` / `grid` 这类短名：design.css 里已有同名全局类，scoped 挡不住——同特异度时只比源码顺序，未声明的属性（padding/align-items）照样被全局规则接管，表现为"我明明没写 padding，它却有留白"。
- 深色主题不重绑被契约测试钉死的色值（`--brand` #015293 等）；页内需要提亮时在 scoped 样式里写 `[data-theme='dark'] ...` 局部覆盖。

## 后端接口
- **JSON 键名不能叫 `name`**：出口脱敏中间件把任何 `name` 当人名，值会被吃成「张****」。用 `check` / `agent_name` / `node_name` / `section_name`。已踩三次（api/asset.py、onto_yaml.py、main.py startup-report）。
- 改后端后必须重启 uvicorn（无 --reload），否则前端看到的还是旧数据。

## 身份与权限（2026-10-25 起）
- **真表**：`sys_role / sys_user / sys_session`（迁移 0040）。密码是 pbkdf2 摘要，会话是 HttpOnly Cookie + 会话表，12 小时过期。
- 服务端 `SessionMiddleware` 拦所有 `/api/*`，白名单只有登录、登出、`/api/iam/roles`（登录页要用）。业务测试用 `FJHY_AUTH_MODE=off` 关掉鉴权，鉴权本身由 `tests/test_iam.py` 覆盖。
- `/api/iam/*`、`/api/auth/*` **整段跳过字段脱敏**：账号名会被闭集合姓名吃成「林*」。手机号在接口里手动按 M03 脱敏，密码摘要永不出接口，x-fjhy-masked 照写。
- 角色与菜单权限的唯一事实来源是数据库；前端 `data/iam.ts` 只是启动时拉一次的响应式缓存。navTree 的 `roles` 字段已退化为历史注释，**不要再按它判断可见性**。
- 系统管理员是内置超管：`permits` 对「用户与角色」「系统自检」硬放行，权限矩阵只读，防自锁。
- **不要把 `app.use(router)` 写在 `iam.init()` 之前**：Vue Router 在 use() 时就跑首次导航，权限缓存还空会被判成无权限、把人踢回登录页。

## 交付前自检
`npx vue-tsc --noEmit` + `npx vitest run`（47 项契约测试）；页面截图验收两档宽度：1440 与 1092（用户实际工作分辨率），确认无横向溢出、无卡片压字。

**表格/多列页面必须扫中间档**：1092 和 1440 都过，不代表 1181–1400 不出横向滚动条——只在两端验证过 `用户与角色` 的表，中间档列宽超了 100px、操作列被切出屏幕。改完表格跑 `var/scan-overflow.cjs`（17 条路由 × 任意宽度，比对 `.app-content` 的 scrollWidth/clientWidth）；表格外层包 `overflow-x:auto` 的容器，让溢出发生在卡片内而不是顶飞整页。
`var/scan-clip.cjs` 更进一步：同时看「可滚动容器 scrollWidth > clientWidth」「元素右边缘越界」，因为 `.panel{overflow:hidden}` 会把内容裁掉而不产生滚动条（页面看着没溢出，实际少一列）。

## 响应式（2026-10-25 起的四档基线，写在 design.css 末尾）
- ≥1281 宽屏原样；≤1280 收紧边距与表格行高；≤1180 卡片可横向滚动（兜底）；≤1080 **侧栏改抽屉**；≤820 单列。
- 新页面直接继承这套，**不要再用整页固定列宽 + 只在 1180 收列**：中间档必炸。
- **栅格不要写内联 `style="grid-template-columns..."`**：内联样式媒体查询压不住，「写了 @media 不生效」十有八九是它。用类名 + scoped 媒体查询。
- 表格列宽要么按内容实测（如「2026-10-24 09:12」需要 135px），要么整列收掉，不许留半截截断。
